Dirección IP Pública

Es una dirección IP única a nivel mundial. Es asignada por tu Proveedor de Servicios de Internet (ISP).

Es la dirección con la que te identificas en Internet. Los servidores web, por ejemplo, tienen IPs públicas para que el mundo pueda acceder a ellos.

Dirección IP Privada

Se utiliza exclusivamente dentro de redes locales (LAN), como tu casa u oficina.

No son visibles en Internet y no se pueden enrutar globalmente. Gracias a esto, millones de hogares pueden usar la misma IP privada (ej. 192.168.1.2) sin chocar.

Traducción NAT

Network Address Translation: Es el proceso donde el Router toma la IP Privada de tu dispositivo, la "enmascara" y la cambia por su IP Pública para que puedas salir a Internet.

Cuando los datos regresan, el router recuerda quién los pidió y se los devuelve a la IP privada correcta. ¡Es un cartero invisible!
