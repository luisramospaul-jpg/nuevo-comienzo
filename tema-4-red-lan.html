Configuración de una Red LAN

El paso a paso práctico para montar una Red de Área Local.

Armando la Red Local (LAN)

Para una red doméstica o de oficina pequeña (usando el rango privado Clase C), el esquema es:

  1. El ISP instala un módem/router.
  2. El router se configura con IP 192.168.1.1 (Gateway).
  3. Se activa el servidor DHCP (asigna IPs del .2 al .254).
  4. Los equipos se conectan por cable o vía Wi-Fi.
La topología más común es la de Estrella, centralizada en el router/switch.

El Router (Enrutador)

Es el "cerebro" de la red local. Su función principal es conectar tu red LAN con Internet (la red WAN).

  • Asigna direcciones IP automáticamente mediante DHCP.
  • Realiza la traducción NAT para que tus dispositivos naveguen.
  • Actúa como cortafuegos (Firewall) básico.
El Switch (Conmutador)

Es el dispositivo encargado de conectar los equipos dentro de la misma red local (LAN).

  • Trabaja en la Capa 2 (Enlace de datos).
  • Utiliza las direcciones MAC para saber a qué puerto enviar los datos.
  • Es mucho más inteligente que un HUB, ya que no envía la información a todos, sino solo al destinatario correcto.
Hosts (Dispositivos Finales)

Son todos los equipos que consumen o generan información en la red (PCs, smartphones, impresoras).

  • Requieren una tarjeta de red (NIC).
  • Deben tener una dirección IP, una máscara de subred y una puerta de enlace (el router) para comunicarse.
